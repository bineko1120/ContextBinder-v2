# ContextBinder v2 UI画面設計マップ

この文書は、少佐が ContextBinder v2 のUIを Visual Studio Designer で作るときに、最初に見る設計図です。

- UIの見た目、配置、余白、色、固定文言：少佐が決める
- ボタンを押したときの処理、保存、検証：Codexが実装する
- 少佐はこの文書を見ながら画面を組み立てる
- Codexは [`UI_CONTROL_CONTRACT.md`](UI_CONTROL_CONTRACT.md) の `Name` 契約へ機能を接続する

現在の実装状況は [`IMPLEMENTATION_MATRIX.md`](IMPLEMENTATION_MATRIX.md)、詳細仕様は [`ContextBinder_v2_SPEC.md`](ContextBinder_v2_SPEC.md) を参照してください。

---

## 1. この文書の使い方

MainFormを作るときは、次の順で見ます。

1. この文書で、画面に必要な領域と機能を確認する
2. Visual Studio Designerで、好きな見た目・場所に配置する
3. [`UI_CONTROL_CONTRACT.md`](UI_CONTROL_CONTRACT.md) で各コントロールの `Name` を設定する
4. 見た目が固まった後、Codexへ機能接続を依頼する

レイアウト例は参考です。少佐が使いやすい配置へ変更して構いません。

---

## 2. 同じ機能に複数の入口を置く

ContextBinderでは、同じ機能に次のような複数の入口を置けます。

| 入口 | 主な用途 | 例 |
|---|---|---|
| 初心者向け文字ボタン | 初見でも意味が分かる | `グループ追加` |
| コンパクトなアイコンボタン | 省スペースで素早く操作する | グループ一覧右上の `＋` |
| MenuStrip | 一般的なWindowsツールとして操作する | `登録 > グループ追加` |
| 右クリックメニュー | 対象を選んだ状態で詳細操作する | `開く`、`コピー`、`編集` |

これらは別の機能ではありません。

```text
初心者向け「グループ追加」ボタン ┐
グループ一覧右上の「＋」ボタン    ├→ 同じグループ追加処理
MenuStripの「グループ追加」       ┘
```

少佐は、それぞれを置く場所や見た目を自由に決められます。Codexはすべてを同じPresenter処理へ接続します。

# 3. MainForm

## 3.1 目的

ContextBinderの中心画面です。

- グループを作成・選択する
- ファイル、フォルダー、画像、動画、URL、テンプレートを登録する
- 登録項目を開く、コピー、編集、削除する
- 検索、絞り込み、並び替え、表示方法を切り替える
- 未保存状態や操作結果を確認する

## 3.2 現在の参考レイアウト

今までの画面構成は、参考として残します。固定仕様ではありません。

```text
┌────────────────────────────────────────────────────┐
│ MenuStrip                                           │
├────────────────────────────────────────────────────┤
│ 検索 / 絞り込み / 並び方 / 表示方法                 │
├─────────────┬──────────────────────┬───────────────┤
│ グループ一覧 │ 項目一覧              │ 操作ボタン     │
│             │ 一覧 / サムネイル     │ 初心者向け等   │
├─────────────┴──────────────────────┴───────────────┤
│ ステータス                                         │
│ 使い方のヒント（表示切替）                         │
│ アイコンの意味（表示切替）                         │
└────────────────────────────────────────────────────┘
```

コンパクト表示では、右側へ操作ボタンをまとめなくても構いません。

例：

```text
グループ                         ＋
────────────────────────────────
TRPG
動画編集
開発
```

この `＋` は、初心者向けの `グループ追加` 文字ボタンと同じ機能です。

## 3.3 必要な領域

| 領域 | 主な内容 | 配置の自由度 |
|---|---|---|
| MenuStrip | ファイル、登録、編集、表示、ツール、ヘルプ | 上部推奨 |
| 検索・表示操作 | 検索、種類絞り込み、並び方、表示方法 | 上部以外でも可 |
| グループ領域 | グループ一覧、グループ追加 | 左側は現行案。変更可 |
| 項目領域 | 登録項目一覧、サムネイル | 中央は現行案。変更可 |
| 操作領域 | 開く、コピー、編集、削除など | 右側または対象付近 |
| 並び替え領域 | 上下移動、保存、保存前に戻す | 項目一覧の近く推奨 |
| 下部情報 | ステータス、ヒント、アイコンの意味 | 下部は現行案。変更可 |

## 3.4 操作ボタン表示モード

### 初心者向け文字表示

- ボタンに操作名を表示する
- 初見で意味が分かることを優先する
- 必要なら大きめのボタンにする
- まとまった操作パネルに置いてもよい

例：

```text
[グループ追加]
[ファイル追加]
[フォルダー追加]
[URL追加]
[テンプレート追加]
[開く]
[コピー]
[編集]
[登録をごみ箱へ]
```

### コンパクトアイコン表示

- 文字なし、または最小限のアイコンを使う
- 操作対象に近い場所へ分散配置してよい
- マウスを乗せるとToolTipを表示する
- `AccessibleName` でも操作名を設定する

例：

```text
グループ一覧右上：＋
項目一覧付近：開く / コピー / 編集 / ごみ箱
並び替え付近：↑ / ↓ / 保存 / 戻す
```

### 共通ルール

- 初心者向けとコンパクト向けは、Designer上に両方置いてよい
- 実行時は設定に応じて表示を切り替える
- MenuStripはどちらの表示モードでも使用できる
- どの入口から操作しても、実行される機能は同じ
- 少佐が配置を決めるため、コンパクトボタンを一つのPanelへまとめる必要はない


## 3.8 並び替え・ソート

置きたい機能：

```text
並び方：[手動並び順 ▼]

[↑ 上へ]
[↓ 下へ]
[並び順を保存]
[保存前に戻す]

● 並び順に未保存の変更があります
```

コンパクト表示では、同じ機能をアイコンだけで表示できます。

```text
[↑] [↓] [保存] [戻す]
```

動作：

- 既定では右ドラッグで手動並び替えする
- 上へ / 下へボタンでも移動できる
- 移動しただけでは正式保存しない
- `並び順を保存` を押した時だけ保存する
- `保存前に戻す` で最後に保存した手動順へ戻す
- 未保存表示は、変更がある時だけ表示する
- 名前順、種類順、追加順、更新順へ切り替えても保存済み手動順は消さない
- 選択範囲だけのソートも将来対応する

---

## 3.9 一覧・サムネイル表示

候補表示モード：

- 通常一覧
- サムネイルつき一覧
- 大きめサムネイル

実装順：

1. 画像サムネイル
2. 動画サムネイル

動画はWindows Shellサムネイルを優先し、読み込み失敗時は通常の種類アイコンを表示します。

# 4. SettingsForm

## 4.1 目的

初回設定後に、表示や操作方法を変更する画面です。

## 4.2 推奨カテゴリ

### 表示

- 種類表示：アイコン＋文字 / アイコンのみ / 文字のみ / 非表示
- 操作ボタン：初心者向け文字 / コンパクトアイコン
- 項目表示：一覧 / サムネイル
- サムネイルサイズ
- 使い方のヒント
- アイコンの意味

### D&D

- D&D追加時にタイトルを確認
- グループへのコピー / 移動確認
- 右ドラッグだけで並び替える / 左右ドラッグを許可
- 外部アプリへファイル、URL、本文を渡す

### 検索・並び順

- 既定の検索範囲
- テンプレート本文も検索
- 既定の並び方
- 未保存並び順：毎回確認 / 自動保存 / 自動破棄

### バックアップ・削除

- 自動バックアップ
- バックアップ保持数
- 削除前確認
- 登録のごみ箱へ移動
- ごみ箱の保持日数（既定30日）
- 手動削除のみ

常に表示する説明：

```text
削除されるのはContextBinderへの登録情報だけです。
元のファイル、フォルダー、画像、動画は削除されません。
```

### 常駐・起動

- 閉じるボタンでタスクトレイへ格納
- Windows起動時に自動起動
- 自動起動時に最小化
- スタートメニュー登録 / 解除
- ショートカット修復

### 保存場所

- 現在の保存場所
- 登録内容と設定フォルダを開く
- 保存場所変更
- 既存内容の移行

# 6. RecycleBinForm / 登録のごみ箱

画面上部に、次の説明を常時表示します。

```text
ここで削除されるのは、ContextBinderへの登録情報だけです。
元のファイル、フォルダー、画像、動画は削除されません。
```

欲しい列：

- 種類
- タイトル
- 元のグループ
- 参照先または内容
- ごみ箱へ入れた日時
- 自動削除予定日

欲しい操作：

- 登録を元に戻す
- ごみ箱から登録を削除
- ごみ箱内の登録情報をすべて削除
- 閉じる

保持期限：

- 既定は30日
- 手動削除のみも選択可能
- 起動時と、起動中は1日1回期限を確認する

# 8. UI完成後にCodexへ伝えること

```text
ContextBinder v2 のUIをVisual Studio Designerで作成しました。

- Designer管理のText / Size / Location / Margin / Padding / Dock / Anchorを変更しないでください。
- docs/UI_SCREEN_MAP.md と docs/UI_CONTROL_CONTRACT.md のName契約に従ってください。
- 文字ボタン、アイコンボタン、MenuStripなど、同じ機能の複数入口を同じPresenter処理へ接続してください。
- 現在配置済みのUIへ、既存機能をPresenter / Service経由で接続してください。
- 未実装機能の入口は、実装されるまでDisabledのまま維持してください。
- UI変更が必要な場合は、変更前に理由と対象を報告してください。
```
