# Icon Assets

ContextBinder v2 で使用する同梱猫アイコン素材です。

| ファイル名 | 用途 |
|---|---|
| `icon_app.png` | メインアプリアイコン候補 |
| `icon_tray.png` | タスクトレイアイコン候補 |
| `icon_cat_folder.png` | フォルダ項目 |
| `icon_cat_file.png` | 通常ファイル項目 |
| `icon_cat_image.png` | 画像ファイル項目 |
| `icon_cat_video.png` | 動画ファイル項目 |
| `icon_cat_url.png` | URL項目 |
| `icon_cat_template.png` | テンプレート文項目 |
| `icon_app.ico` | アプリ本体・MainFormアイコン |
| `icon_tray.ico` | NotifyIcon |
